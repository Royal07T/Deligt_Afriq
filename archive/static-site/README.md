# Delight Afriq

A premium African fashion website showcasing bespoke fashion, ready-to-wear collections, and statement accessories. Delight Afriq brings African heritage to modern luxury with elegant designs for special occasions and everyday confidence.

## 🌟 Features

- **Premium Design**: Editorial fashion aesthetic with refined typography and smooth animations
- **Responsive Layout**: Fully responsive design optimized for desktop, tablet, and mobile devices
- **Product Showcase**: Dynamic product grid with filtering by category
- **WhatsApp Integration**: Direct WhatsApp contact for inquiries and orders
- **Editorial Gallery**: Masonry layout gallery with video content
- **Contact Form**: Professional inquiry form for custom orders and consultations
- **Brand Story**: Authentic brand narrative and experience sections
- **Sticky Navigation**: Easy-to-use navigation with mobile hamburger menu

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Royal07T/Deligt_Afriq.git
```

2. Navigate to the project directory:
```bash
cd Deligt_Afriq
```

3. Open `index.html` in your web browser to view the website

### Development

For development with live reloading, you can use a local server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server
```

Then open `http://localhost:8000` in your browser.

### Products

Edit product data in `script.js`:
```javascript
const products = [
  {
    name: "Product Name",
    category: "Category Name",
    type: "Price on Request",
    description: "Product description",
    image: "image-file.jpg"
  }
];
```

### Colors and Styling

Modify CSS variables in `styles.css`:
```css
:root {
  --primary: #0c1a3a;
  --accent: #c9a227;
  --heading: #0a1226;
  --body: #4a5568;
  /* ... more variables */
}
```
